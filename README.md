# Shayan Akhtar - Developer & AI Engineer Portfolio 🚀

Personal Developer Portfolio built with React, styled-components, and modern web animations, powered by the [masterPortfolio](https://github.com/ashutosh1919/masterPortfolio) template.

## 🌟 Features
- **Splash Screen Animation** with customized signature font
- **About & Skills** (AI/ML, Full Stack Development, Data Analysis, Cloud Architecture)
- **Education** (Lovely Professional University - B.Tech CSE; Narayana Junior College)
- **Certifications** (AgentIQ Datathon 2026, NPTEL Privacy & Security, Binary Blitz, AWS, GenAI, Java Maestro)
- **Featured Projects** (AgroBuddy, Telecom Churn Prediction, EasyInvoice AI, FraudLens, PyDebug, Java Multi-Tier App, TollTax System)
- **Interactive Contact Form** (Powered by EmailJS)
- **PDF Resume Viewer & Downloader**

## 🛠️ Tech Stack
- **Frontend**: React 16, styled-components, react-reveal, react-router-dom, react-bootstrap, baseui
- **Icons & Styling**: FontAwesome, BaseUI, CSS3 animations, Agustina signature typography
- **Integration**: EmailJS Browser SDK

## 🚀 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/shayan-codes-405/Shayan_Portfolio.git
   cd Shayan_Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install --legacy-peer-deps
   ```

3. **Start the development server:**
   ```bash
   npm start
   ```
   Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

4. **Build for production:**
   ```bash
   npm run build
   ```
