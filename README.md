## 🛠️ Local Setup & Running Instructions

To run this portfolio website locally on your system:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/shayan-codes-405/Shayan_Portfolio.git
   cd Shayan_Portfolio
   ```

2. **Open in Browser**:
   - Double-click `index.html` to open it in your default web browser, OR
   - Use VS Code **Live Server** extension for live reloading.
